# 基于 YOLOv8 的港口人员不安全行为检测

基于 YOLOv8 的 11 类目标检测项目，面向港口/船舶作业场景，自动识别作业人员的安全装备佩戴情况与不安全行为，为港口安全生产监管提供视觉化的技术方案。

- **任务类型**：单阶段目标检测（Object Detection）
- **检测模型**：YOLOv8m（迁移学习 + 两阶段训练）
- **类别数量**：11 类（人员状态 / 安全装备 / 不安全行为 / 环境风险）
- **数据规模**：5,978 张图像，约 12,900 个标注框
- **最终效果**：测试集 mAP@0.5 = 0.608，mAP@0.5:0.95 = 0.356；关键风险类别（未戴安全帽 0.870、港口作业 0.873、安全帽 0.845）mAP@0.5 均超过 0.84

---

## 1. 项目作用

港口是典型的高风险作业场所，人员未佩戴安全帽/救生衣、吸烟、违规使用手机等不安全行为是事故的重要诱因。传统人工巡检存在覆盖面有限、主观性强、难以全天候监督等问题。

本项目以计算机视觉手段替代/辅助人工巡检，核心价值包括：

- **自动发现风险行为**：对未戴安全帽、未穿救生衣、吸烟、打电话、疲劳作业等 6 类不安全状态进行自动识别，可作为告警系统的检测前端；
- **区分"人"与"装备"**：同时检测人员整体状态（戴/未戴头盔的人）与装备个体（安全帽、救生衣），便于统计区域合规率；
- **覆盖环境风险**：将危险区域/警示标志纳入检测范围，支持"人员 + 行为 + 环境"的联合分析；
- **低成本可复现**：全部训练在单张 8GB 显存的消费级 GPU 上完成，无需大规模算力。

---

## 2. 系统架构

项目整体分为数据层、训练层与应用层三部分：

```text
data_merged（5,978 张图像，11 类 YOLO 格式，8:1:1 划分）
│
├──▼（数据层）
│  DataMerge / ClassRemap
│  7 个来源：自采集港口图像（265 张有效标注）
│            + 6 个公开数据集（Kaggle / Roboflow，CC BY 4.0）
│  → 类别 ID 映射（各源类别 → 统一 11 类）
│  → 多边形标注转 bbox / 无效数据过滤
│  → 优势类别下采样（helmet 类 72,000+ 框 → 6,450 框）
│
├──▼（训练层）
│  YOLOv8m（COCO 预训练，迁移学习）
│  → 主训练：100 epochs，在线增强（Mosaic 1.0 / MixUp 0.1 / 旋转 ±15°）
│  → 低学习率微调：20 epochs，lr=1e-4，稳定高 IoU 定位精度
│  → 最终权重 best.pt（11.1M 参数 / 28.5 GFLOPs，8GB 显存可训）
│
└──▼（应用层）
   Inference
   单张图片推理 / 批量推理（599 张测试图）/ 视频流推理（扩展）
   → 检测框可视化（类别 + 置信度） → 告警输出
   → 单张端到端约 8.6 ms，等效帧率 > 100 FPS
```

各层职责：

| 层级 | 核心逻辑 |
|:---|:---|
| 数据层 | 将来源各异（不同类别体系、不同标注格式）的数据统一为同一套 11 类 YOLO 格式，并缓解类别不平衡 |
| 训练层 | 以 COCO 预训练的 YOLOv8m 为起点，先在大规模强增强下主训练，再以低学习率微调收敛 |
| 应用层 | 基于训练好的权重进行单张 / 批量 / 视频推理，输出带类别与置信度的可视化检测结果 |

## 4. 数据集构建逻辑

### 4.1 数据来源

| 来源 | 类型 | 图片数 | 说明 |
|:---|:---|:---:|:---|
| 自采集港口场景 | 自主收集 | 265 张有效标注 | 项目基础数据，合并时优先保留 |
| Kaggle 安全帽检测 | 公开数据集（CC BY 4.0） | 27,703 张 | 3 类：Helmet / No Helmet / Worker |
| Roboflow 吸烟检测 | 公开数据集（CC BY 4.0） | 1,122 张 | cigarettes / smoking |
| Roboflow 救生衣检测 | 公开数据集（CC BY 4.0） | 331 张 | 5 类中取 3 类 |
| Roboflow 打电话检测 | 公开数据集（CC BY 4.0） | 300 张 | hand_phone |
| Roboflow 码头作业 | 公开数据集（CC BY 4.0） | 500 张 | 多边形分割标注 |
| Roboflow 危险标志 | 公开数据集（CC BY 4.0） | 194 张 | 5 类全部归入 danger |

> 数据集的完整来源明细、类别映射表与合并脚本逻辑见仓库中的 [数据集构建.md](./数据集构建.md)。

### 4.2 合并与清洗策略

1. **类别映射**：各数据集的原始类别 ID 通过配置表统一映射到目标 11 类体系；
2. **格式转换**：码头作业数据集的原始多边形（segmentation）标注，通过取外接矩形自动转换为 YOLO bbox 格式；
3. **无效数据过滤**：剔除无标注文件、类别无法映射的图片；一个二分类"疲劳"数据集因无检测标注被整体剔除，疲劳类样本完全来自自采集数据；
4. **优势类别下采样**：原始合并后约 28,777 张图中 helmet 类超过 72,000 个框（占比 > 50%），对 `people without helmet` 与 `helmet` 两类按 10% 比例下采样，最终 helmet 类降至 6,450 框，图片总量压缩约 79%；
5. **统一划分**：整体打乱后按 **8 : 1 : 1** 随机划分为训练 / 验证 / 测试集（seed 固定，保证可复现）。

### 4.3 最终数据规模

| 划分 | 图片数 | 用途 |
|:---:|:---:|:---|
| train | 4,778 | 训练（约 12,945 个标注框） |
| val | 601 | 验证与模型选择 |
| test | 599 | 最终评估（1,499 个标注框） |

### 4.4 数据增强

不采用离线增强（不生成新图片文件），全部增强在训练时在线完成：

| 增强方式 | 参数 | 说明 |
|:---|:---:|:---|
| 水平 / 垂直翻转 | 0.5 / 0.1 | 模拟不同朝向 |
| 随机旋转 | ±15° | 模拟摄像头角度变化 |
| 随机缩放 / 平移 | 0.5 / 0.1 | 模拟距离与位置变化 |
| HSV 扰动 | h 0.015 / s 0.7 / v 0.4 | 模拟光照与天气变化 |
| Mosaic | 1.0 | 四图拼接，提升小目标与上下文鲁棒性 |
| MixUp / Copy-Paste | 0.1 / 0.1 | 图像混合与目标粘贴 |
| Random Erasing | 0.4 | 模拟遮挡 |

## 5. 模型训练逻辑

### 5.1 两阶段训练

**阶段一：主训练**

- 基础模型：COCO 预训练 `yolov8m.pt`（迁移学习）
- 训练轮数：100 epochs（早停机制，实际收敛于约 90 epochs）
- 输入尺寸：640 x 640，batch size = 8
- 优化器：AdamW，初始学习率 0.01，权重衰减 0.0005
- 激活上文 4.4 节的全部在线增强策略

**阶段二：低学习率微调**

- 从阶段一的最优权重（按 val mAP50 选出）继续训练
- 训练轮数：20 epochs，初始学习率降至 0.0001，batch size 提升至 16
- 关闭旋转 / MixUp 等强增强，让模型在小扰动下精细收敛
- 目的：稳定高 IoU 阈值下的定位精度，提升 mAP@0.5:0.95

### 5.2 模型网络结构（YOLOv8m）

```text
输入图像 640 x 640 x 3
│
├──▼ Backbone（主干网络，CSPDarknet）
│  Conv（卷积 + BN + SiLU）/ C2f（跨阶段部分融合，含梯度流分支）/ SPPF
│  逐级下采样，输出三尺度特征图：
│  → P3（80 x 80，stride 8）  —— 检测小目标（远景人员、安全帽）
│  → P4（40 x 40，stride 16） —— 检测中目标
│  → P5（20 x 20，stride 32） —— 检测大目标（近景人员、危险区域）
│
├──▼ Neck（特征融合，PAN-FPN）
│  自顶向下路径（P5 → P4 → P3）+ 自底向上路径（P3 → P4 → P5）
│  → 输出融合了深层语义与浅层细节的三级增强特征
│
└──▼ Head（检测头，Decoupled / Anchor-Free）
   分类与回归分支解耦（两条独立卷积分支）
   → 分类分支：输出 11 类概率（人员状态 / 装备 / 行为 / 环境风险）
   → 回归分支：DFL 分布式焦点损失回归边界框（4 坐标）
   → Anchor-Free 无锚框设计，TaskAlignedAssigner 动态标签分配
   → 后处理 NMS → 检测结果（类别 + 边界框 + 置信度）
```

结构要点：YOLOv8 系列采用 Anchor-Free 解耦头与 C2f 模块（相比 YOLOv5 的 Anchor-Based 耦合头与 C3 模块），在保持推理速度的同时提升了对小目标与多尺度目标的召回能力，这与本项目"远景小目标人员 + 局部行为特征（吸烟、打电话）"的检测需求相匹配。

### 5.3 模型规模对比

在同一数据集上对比了 YOLOv8n 与 YOLOv8m 两种规模（验证集指标）：

| 模型 | 验证集 mAP@0.5 | 特点 |
|:---|:---:|:---|
| YOLOv8n | 0.668 | 参数少、速度快 |
| **YOLOv8m（最终采用）** | **0.687** | 精度更高，微调后高 IoU 精度明显改善 |

最终模型（YOLOv8m，fused）参数量约 11.1M，计算量 28.5 GFLOPs，在精度与 8GB 显存约束之间取得平衡。

| 阶段 | 耗时 / 张 |
|:---|:---:|

单张端到端约 8.6 ms，等效帧率超过 100 FPS，满足准实时检测需求。

### 6.4 结果分析

**表现较好的类别**：`people without helmet`、`wharf handling`、`helmet`、`smoking` 等，要么数据量充足，要么外观特征明显。其中最核心的违规类别"未戴安全帽"达到 0.870，验证了技术路线的有效性。

**表现较弱的类别及归因**：

- `phoning`（0.203）：全数据集仅约 100 个训练框，测试集仅 13 个实例，属于典型的长尾类别；
- `people with helmet`（0.166）：该类要求"人 + 帽"同时命中，与独立的 `helmet`、人员类别存在语义重叠，模型易混淆；同时其测试样本中包含大量远景小目标；
- `tired`：仅 39 个训练框，来自自采集数据，外部疲劳数据集因缺少检测标注无法合并。

**改进方向**：补充长尾类别（打电话、疲劳）样本；引入 Focal Loss 或更激进的过采样策略；将 `people with helmet` 改为由 `person + helmet` 检测结果后处理逻辑推导，避免类别冗余。

## 9. 环境复现

**环境要求**：Python 3.9 - 3.12，PyTorch（CUDA 版），ultralytics。

```bash
pip install ultralytics
```

**训练流程**（与本项目一致的超参数）：

```python
from ultralytics import YOLO

# 阶段一：主训练
model = YOLO("yolov8m.pt")
model.train(
    data="data.yaml",       # 指向 data_merged 的配置文件
    epochs=100, batch=8, imgsz=640,
    optimizer="AdamW", lr0=0.01, weight_decay=0.0005, patience=50,
    fliplr=0.5, flipud=0.1, degrees=15, scale=0.5, translate=0.1,
    mosaic=1.0, mixup=0.1, copy_paste=0.1, erasing=0.4,
)

# 阶段二：低学习率微调（从阶段一 best.pt 继续）
finetune = YOLO("runs/detect/train/weights/best.pt")
finetune.train(
    data="data.yaml", epochs=20, batch=16, imgsz=640,
    optimizer="AdamW", lr0=0.0001, patience=100,
    degrees=0, mixup=0.0,
)

# 测试集评估
metrics = finetune.val(split="test")
```

**推理**：

```python
from ultralytics import YOLO

model = YOLO("best.pt")
results = model("path/to/image.jpg", conf=0.25)
```
